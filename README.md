# RoomRescue

RoomRescue is a Flutter application for viewing rooms and reporting room-related issues.

## Run locally

Install the Flutter SDK, then clone and run the project:

```sh
git clone https://github.com/z-khz/RoomRescue.git
cd RoomRescue
flutter pub get
flutter run
```

Firebase client configuration is included for the configured app. Protect data and services
with appropriate Firebase security rules; client configuration is not an authorization boundary.
